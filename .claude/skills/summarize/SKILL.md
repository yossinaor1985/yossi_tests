Summarize $ARGUMENTS clearly and concisely.

Follow these steps:
1. Read the file or identify the topic from $ARGUMENTS
2. Identify the key themes, functions, or concepts
3. Present a structured summary using the format below

## Output format

**Overview**: One sentence describing what it is.

**Key Points**:
- Bullet 1
- Bullet 2
- Bullet 3
(up to 7 bullets max)

**Notable Details**: Any important caveats, patterns, or things worth highlighting.

Keep the summary brief. Avoid restating obvious things. Focus on what is most useful to know.
