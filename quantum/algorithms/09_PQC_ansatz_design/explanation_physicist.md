# Parameterized Quantum Circuits (PQC) & Ansatz Design - Physicist's Deep Dive

## 1. Overview

Parameterized Quantum Circuits (PQCs), also called variational circuits or ansatze (plural of ansatz), are the fundamental building blocks of all variational quantum algorithms (VQE, QAOA, QML). A PQC is a quantum circuit containing gates whose parameters (rotation angles) are adjustable. These parameters are optimized classically to minimize a cost function.

Understanding PQC design is essential because the choice of ansatz critically determines:
- **Expressibility:** Which states the circuit can represent
- **Trainability:** Whether gradients vanish (barren plateaus)
- **Efficiency:** Circuit depth and gate count
- **Entangling capability:** How much entanglement can be generated

## 2. Mathematical Framework

### 2.1 General Form of a PQC

A PQC on n qubits with L layers has the form:

```
U(theta) = U_L(theta_L) * W_L * U_{L-1}(theta_{L-1}) * W_{L-1} * ... * U_1(theta_1) * W_1
```

where:
- U_l(theta_l) are parameterized gates (typically single-qubit rotations)
- W_l are fixed entangling blocks (typically CNOT or CZ layers)
- theta = (theta_1, ..., theta_p) is the parameter vector

The output state is:
```
|psi(theta)> = U(theta) |0>^n
```

### 2.2 Single-Qubit Rotation Gates

The three basic rotation gates form a universal single-qubit gate set:

```
R_X(theta) = exp(-i theta X / 2) = [cos(theta/2), -i*sin(theta/2); -i*sin(theta/2), cos(theta/2)]

R_Y(theta) = exp(-i theta Y / 2) = [cos(theta/2), -sin(theta/2); sin(theta/2), cos(theta/2)]

R_Z(theta) = exp(-i theta Z / 2) = [exp(-i*theta/2), 0; 0, exp(i*theta/2)]
```

Any single-qubit unitary U in SU(2) can be decomposed as:
```
U = R_Z(alpha) R_Y(beta) R_Z(gamma) * exp(i*delta)
```
(Euler angle decomposition, 3 parameters)

### 2.3 Entangling Gates

Common entangling gates:

**CNOT (CX):**
```
CX = |0><0| tensor I + |1><1| tensor X
```
Creates entanglement by flipping the target qubit conditioned on the control.

**CZ:**
```
CZ = |0><0| tensor I + |1><1| tensor Z
```
Applies a phase flip conditioned on both qubits being |1>.

**ECR (Echoed Cross-Resonance):**
Native gate on IBM hardware. Equivalent to:
```
ECR = (1/sqrt(2)) * (IX - XY)
```

## 3. Common Ansatz Architectures

### 3.1 Hardware-Efficient Ansatz (HEA)

Structure:
```
|psi> = [prod_{l=1}^{L} ENT_l * ROT_l] |0>^n
```

where ROT_l = tensor_{i=1}^{n} R_Y(theta_{l,i,1}) R_Z(theta_{l,i,2})
and ENT_l is a fixed entangling pattern (e.g., linear CNOT chain).

**Parameters per layer:** 2n (one R_Y and one R_Z per qubit)
**Total parameters:** 2nL + 2n (including final rotation layer)

**Qiskit:** `EfficientSU2(num_qubits, reps=L)`

### 3.2 RealAmplitudes Ansatz

Same as HEA but using only R_Y rotations (no R_Z):
```
ROT_l = tensor_{i=1}^{n} R_Y(theta_{l,i})
```

This produces states with only real amplitudes (no complex phases).

**Parameters per layer:** n
**Qiskit:** `RealAmplitudes(num_qubits, reps=L)`

### 3.3 TwoLocal Ansatz

Generalizes HEA with configurable:
- Rotation gates (any combination of R_X, R_Y, R_Z)
- Entangling gates (CX, CZ, CRX, CRZ, etc.)
- Entanglement pattern (linear, reverse_linear, full, circular, sca)

**Qiskit:** `TwoLocal(num_qubits, rotation_blocks, entanglement_blocks, reps=L)`

### 3.4 NLocal Ansatz

Further generalization allowing k-local interactions (k-qubit gates):
```
|psi> = [prod_l ENT_l(theta_ent) * ROT_l(theta_rot)] |0>
```

Both rotation AND entangling blocks can be parameterized.

### 3.5 QAOA Ansatz (QAOAAnsatz)

Problem-specific ansatz for combinatorial optimization:
```
U(gamma, beta) = prod_{l=1}^{p} [exp(-i beta_l H_M) * exp(-i gamma_l H_C)]
```

Only 2p parameters. Structure determined by the problem Hamiltonian H_C.

**Qiskit:** `QAOAAnsatz(cost_operator, reps=p)`

## 4. Expressibility

### 4.1 Definition

The expressibility of a PQC quantifies how uniformly it can explore the Hilbert space. Formally, it is measured by the divergence between the ensemble of states generated by the PQC and the Haar-random ensemble:

```
Expr = D_KL(P_PQC(F) || P_Haar(F))
```

where F = |<psi(theta_1)|psi(theta_2)>|^2 is the fidelity between two random states from the PQC, and D_KL is the Kullback-Leibler divergence.

**Low expressibility number = high expressibility** (closer to Haar-random)

### 4.2 Expressibility Hierarchy

From least to most expressive (for fixed depth):
1. Product state circuits (no entanglement): can only reach product states
2. RealAmplitudes: real-valued amplitudes only
3. EfficientSU2: full SU(2) rotations per qubit
4. TwoLocal with full entanglement: approaches universal
5. General unitary (exponential parameters): exactly universal

### 4.3 Expressibility vs Trainability Trade-off

**More expressive circuits tend to be harder to train!**

Highly expressive circuits explore the Hilbert space too uniformly, leading to:
- Flat cost function landscapes (barren plateaus)
- Exponentially vanishing gradients
- Concentration of the cost function around its mean value

## 5. Entangling Capability

### 5.1 Meyer-Wallach Entanglement Measure

The entangling capability Q of a PQC is:

```
Q = (2/n) sum_{k=1}^{n} (1 - Tr(rho_k^2))
```

where rho_k = Tr_{not k}(|psi><psi|) is the reduced density matrix of qubit k.

Q = 0 for product states, Q = 1 for maximally entangled states.

### 5.2 Entanglement Patterns

| Pattern | Connectivity | CNOT count per layer |
|---------|-------------|---------------------|
| Linear | i -> i+1 | n-1 |
| Reverse linear | i+1 -> i | n-1 |
| Full | all pairs | n(n-1)/2 |
| Circular | linear + n-1 -> 0 | n |
| SCA (shifted circular alt.) | shifted circular | n |

**Linear** is most hardware-friendly (matches nearest-neighbor connectivity).
**Full** is most expressive but requires SWAP routing on real hardware.

## 6. Barren Plateaus

### 6.1 The Problem

For a randomly initialized PQC with sufficient depth, the variance of the gradient vanishes exponentially:

```
Var[dC/d(theta_j)] <= F(n) * 2^{-n}
```

where F(n) is at most polynomial in n. This means:
- For n = 20 qubits: gradient ~10^{-6}
- For n = 50 qubits: gradient ~10^{-15}
- Impossible to detect a gradient signal above shot noise!

### 6.2 Causes

1. **Deep random circuits:** approach 2-designs, creating flat landscapes
2. **Global cost functions:** measure properties of the entire state
3. **Entanglement entropy:** highly entangled states have exponentially flat energy landscapes
4. **Hardware noise:** adds noise-induced barren plateaus

### 6.3 Mitigation Strategies

1. **Problem-inspired ansatze:** UCCSD, QAOA, HVA (Hamiltonian Variational Ansatz)
2. **Shallow circuits:** Keep depth O(log(n)) or O(1)
3. **Local cost functions:** Use local observables instead of global ones
4. **Parameter initialization:** Start near identity (small random angles)
5. **Layer-wise training:** Train one layer at a time, then add the next
6. **Correlated parameters:** Share parameters across layers

## 7. Parameter Initialization Strategies

### 7.1 Random Small

```
theta_j ~ Uniform(-epsilon, epsilon),  epsilon << 1
```
Keeps the circuit close to the identity, avoiding deep random circuit regime.

### 7.2 Identity Initialization

Set all parameters to 0. The circuit is the identity, and |psi> = |0>^n.
First gradient step breaks symmetry.

### 7.3 Classical Pre-training

Use a classical simulation (e.g., tensor network) to find approximate parameters,
then refine on the quantum computer.

### 7.4 Layer-wise Training

```
1. Train layer 1 alone (fix others at 0)
2. Fix layer 1, train layer 2
3. ...
4. Fine-tune all layers together
```

## 8. Feature Maps for QML

In quantum machine learning, a **feature map** encodes classical data x into a quantum state:

```
|phi(x)> = U_phi(x) |0>^n
```

Common feature maps:

### 8.1 ZFeatureMap
```
U_phi(x) = [prod_{l=1}^{r} H^n * prod_i exp(i x_i Z_i)] |0>^n
```

### 8.2 ZZFeatureMap
Adds pairwise interactions:
```
U_phi(x) = [prod_{l=1}^{r} H^n * prod_i exp(i x_i Z_i) * prod_{i<j} exp(i (pi - x_i)(pi - x_j) Z_i Z_j)] |0>^n
```

### 8.3 PauliFeatureMap
General Pauli rotations: configurable entanglement and Pauli strings.
